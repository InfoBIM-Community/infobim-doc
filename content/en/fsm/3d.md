### `StandardInfoBIMIfcViewer` { #fsm-standardinfobimifcviewer }

<div class="fsm-reference-title" markdown="1">InfoBIM IFC 3D Viewer</div>

<div class="cli-reference-label">Description</div>

Open the requested IFC file with IfcOpenShell, triangulate one Qt Quick 3D geometry per element, and show them in the InfoBIM 3D viewer.


<div class="cli-reference-label">States</div>

<div class="fsm-reference-states" markdown="1">


<div class="fsm-reference-state" markdown="1">

Undefined

<span class="fsm-reference-value">`__undefined__`</span>

<span class="fsm-reference-description">Initial state before the IFC file is opened.</span>



</div>

<span class="fsm-reference-arrow">↓</span>



<div class="fsm-reference-state" markdown="1">

IFC Document Loaded

<span class="fsm-reference-value">`__ifc_document_loaded__`</span>

<span class="fsm-reference-description">The IFC file was opened with IfcOpenShell and its model was injected into the context.</span>



</div>

<span class="fsm-reference-arrow">↓</span>



<div class="fsm-reference-state" markdown="1">

IFC Qt Quick 3D Geometries Created

<span class="fsm-reference-value">`__ifc_quick3d_geometries_created__`</span>

<span class="fsm-reference-description">Every IFC element with geometry was triangulated in world coordinates into a Qt Quick 3D geometry that keeps its GlobalId, Name and IFC type.</span>



</div>
